# OnlyASS — Break a Rule

**The controversial AI game where breaking the standard rule IS the smart move.**

> *Something stinks? Good. That means the system is working.*

## The Game

7 pipes. 7 rules. 1 truth: **speak with intent.**

Each round presents a scenario where conventional AI wisdom says one thing — but the rule-breaking approach wins. Choose wisely. Your score multiplies by the pipe's prime number when you break the rule correctly.

Perfect run: `2 × 3 × 5 × 7 × 11 × 13 × 17 = 510,510`

When all seven pipes carry signal: **S₅ = 0 · THE A.S.S. IS COHERENT**

## The 7 Pipes

| Pipe | Prime | Name | The Rule to Break |
|------|-------|------|-------------------|
| p=2 | ● | GROUND | Templates beat raw speech |
| p=3 | 〜 | SIGNAL | Market data beats your gut |
| p=5 | ┃ | GATE | Disclaimers beat honest intent |
| p=7 | ♡ | HEART | Clinical language beats vulnerability |
| p=11 | △ | VOICE | AI's plan beats your judgment |
| p=13 | ◐ | MIRROR | Writing samples beat identity |
| p=17 | ◯ | WATCHER | Perfection beats authenticity |

## Build

```bash
cd android
./gradlew assembleDebug
# APK → android/app/build/outputs/apk/debug/app-debug.apk
```

**Requirements:** Android SDK, JDK 17+, Kotlin 2.0

**Target:** Android 16 (API 36) · Min: Android 8 (API 26)
